# Opt-in

Consentimento prévio e explícito para receber comunicação por um canal. Para WhatsApp comercial é exigência da operadora da API e da LGPD. Sem opt-in, só e-mail transacional (fatura e segunda via). Ver [[D-27 WhatsApp só com opt-in]].

Na prática, registramos o consentimento no onboarding do cliente, com data e canal. Revogar vale imediatamente: se o cliente pede para parar, o ciclo de cobrança deve ignorar o canal na mesma hora. Para o jurídico, a prova do consentimento é a data guardada, por isso nunca sobrescrevemos o registro, só acrescentamos um novo.
