# Preparar um release

- [ ] Changelog atualizado
- [ ] Migrações revisadas (nada que bloqueie tabela grande)
- [ ] Testes verdes na CI
- [ ] Aviso ao suporte se mexe em cobrança
- [ ] Janela: terça a quinta, nunca sexta nem véspera de virada de mês
- [ ] Plano de volta escrito
