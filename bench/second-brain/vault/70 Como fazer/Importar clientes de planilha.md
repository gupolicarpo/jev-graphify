# Importar clientes de planilha

Modelo de planilha: nome, documento, município (IBGE), e-mail, telefone. Valide cada linha com `validate_cnpj` ou `validate_cpf`; linhas inválidas vão para um relatório de rejeição, nunca são corrigidas silenciosamente. Documentos repetidos atualizam o cadastro, não criam outro.
